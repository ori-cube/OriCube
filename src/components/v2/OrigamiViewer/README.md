# V2 閲覧の再生処理

`ProcedureV2` を `createViewerTimeline` へ渡し、折りと裏返しの閲覧ステップを作る。保存形式・V1 のビューアーは変更しない。`history[index].viewFront` が前の手順と異なるときだけ裏返しを挿入する。履歴が空の場合は直前の向きを維持する。

閲覧は `steps[].moveBoards[].vertexAxes` を順に回転するだけで、折りのソルバやジェスチャのリプレイを呼ばない。`targetAngle` は折りの終点に使用し、平面プロキシの `finalBoards` へ仕上げ角度を復元する。対象外の固定板の仕上げ角度も保持する。

`OrigamiCanvas` はその結果を描画する。スライダー操作・明示的な再生・視点変更・リサイズ時にだけ描画し、停止中の描画ループは持たない。ステップ変更でメッシュを作り、進捗更新では position 属性を更新する。離脱時にリサイズ監視・イベント・ジオメトリ・マテリアル・WebGLRenderer を破棄する。

V2 は裏返しボタンそのものの操作履歴を保存していないため、折りの間で表裏が変わらない複数回の裏返しや、最後の折り以降の裏返しは復元できない。これらを保存する必要が生じた場合は、投稿側と保存形式に明示的な視点操作の履歴を追加する。
