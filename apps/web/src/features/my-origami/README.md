# 自分の作品（`/me`）

ログインした人の作品を並べ、見る・再編集する・削除する画面（`MyOrigamiList.tsx`）。

- `GET /api/me/models` で、限定公開・公開前（`pending`）の作品も含めて新しい順に並べる。公開範囲と状態をカードに書く
- 「見る」は作品ページ、「編集する」は作成画面の再編集（`/post?edit=<作品ID>`。`apps/web/src/features/post-editor/README.md` の再編集）
- 公開前の作品はサムネイルが確定していないため、見る・編集はできず削除だけできる
- 削除は design-system の `ConfirmDialog` で確かめてから `DELETE /api/models/:id`。作品とサムネイルを完全に消し、元に戻せない（#100 の保存契約）。ブラウザの下書きは消さない
- 未ログイン・セッション切れならログインを促し、ログイン後はこの画面へ戻る。ログインの設定がない環境では API に任せ（`pnpm dev:api` は開発ユーザーの作品を返す）、拒否されたら表示できないことを伝える
- ヘッダーの「自分の作品」（ログイン中だけ）から開く
