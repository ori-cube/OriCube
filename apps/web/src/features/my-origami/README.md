# 自分の作品（`/me`）

このブラウザで投稿した作品を並べ、見る・再編集する・削除する画面（`MyOrigamiList.tsx`）。

- ログインが無いため、サーバーには「自分の作品」の一覧は無い。このブラウザに編集用の鍵（`post-editor/editKeys.ts`）がある作品を、新しく投稿した順に `GET /api/models/:id` で1件ずつ読む。見つからない作品（他のブラウザで削除したなど）は除く
- 表紙は一覧・OGP と同じ完成形の図を、読み込んだ手順から画面で作る。公開範囲をカードに書く
- 「見る」は作品ページ、「編集する」は作成画面の再編集（`/post?edit=<作品ID>`。`apps/web/src/features/post-editor/README.md` の再編集）
- 削除は design-system の `ConfirmDialog` で確かめてから、`X-Edit-Key` に鍵を付けて `DELETE /api/models/:id`。作品を完全に消し、元に戻せない（#100 の保存契約）。消したら鍵もブラウザから消す。ブラウザの下書きは消さない
- ブラウザのデータを消すと鍵も消え、ここに出なくなり編集・削除もできない
- ヘッダーの「自分の作品」から開く
