# V2 閲覧の再生処理

`ProcedureV2` を `createViewerTimeline` へ渡し、折りと裏返しの閲覧ステップを作る。`version: 3` は `history` に保存した裏返し（`kind: "flip"`）をそのまま再生する。`version: 2` は裏返しを保存していないため、`history[index].viewFront` が前の手順と異なるときだけ裏返しを挿入し、履歴が空の場合は直前の向きを維持する。

閲覧は `steps[].moveBoards[].vertexAxes` を順に回転するだけで、折りのソルバやジェスチャのリプレイを呼ばない。`targetAngle` は折りの終点に使用し、平面プロキシの `finalBoards` へ仕上げ角度を復元する。対象外の固定板の仕上げ角度も保持する。

`OrigamiCanvas` はその結果を描画する。スライダー操作・明示的な再生・視点変更・リサイズ時にだけ描画し、停止中の描画ループは持たない。ステップ変更でメッシュを作り、進捗更新では position 属性を更新する。離脱時にリサイズ監視・イベント・ジオメトリ・マテリアル・WebGLRenderer を破棄する。

`version: 3` では折りの間の往復の裏返しや、最後の折りの後の裏返しも閲覧ステップになる。`version: 2` のデータ（鶴のモックなど）ではこれらは復元できない。

## 完成形を見せる向き

対角線で折る鶴のように、折ったときの向きのままだと完成形が傾いて見える作品がある。作品の `presentation.rotation`（単位クォータニオン、engine の `PresentationV2`）があれば、最後に「完成形の向きに整える」ステップを足し、折り終えた形をその向きへ回す（`getPresentationRotation` で回転なしから補間）。

- 折る途中の手順は折ったときの向きのまま見せる。手元の紙と見比べながら折るため
- 回転は完成形の中心を原点にし、最後の表裏に合わせて Y 軸周りに回したあとの表示座標に掛ける。シーンでは板をまとめたグループの親（pose）に入れる
- 向きは投稿画面でサムネイルの向きを決めたときに決まる。無い作品はステップを足さず、今までどおり表示する
- 手順のない作品は、ステップを足さずに完成形を回した向きで表示する
